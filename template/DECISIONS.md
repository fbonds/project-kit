# Decided, do not redo

The decisions for PROJECT. A session reads this file at the start, after `NEXT.md`.

What was settled and why, what was ruled out and why, and anything the owner said not to
do. A resumed session that sees only the remaining tasks will rebuild something already
rejected, or argue for an option already refused.

An entry in force is not rewritten. To change a decision, get the owner's approval, then add
a new entry with its date, its reasoning and what it replaces, and delete the entry it
replaces in the same commit. The commit message names the deleted entry, and the git history
keeps its text. When this file passes 2,000 words by `wc -w`, an entry about a closed matter,
whose substance another file in the repo already records, may be deleted the same way, with
the commit naming the file that records it.
